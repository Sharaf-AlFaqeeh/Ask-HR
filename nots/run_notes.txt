### 2️⃣ خدمة Orchestrator + الواجهة (بورت 8081)

⚠️ ملاحظة مهمة: يجب التشغيل من المجلد الرئيسي للمشروع وليس من مجلد orchestrator_service
   تشغيل python main.py من داخل مجلد orchestrator_service يسبب خطأ WinError 10013
   بسبب مشاكل uvicorn reload مع مسارات Windows.

```powershell
# ── تشغيل (في تيرمنل ثاني) ──
cd P:\____AI____\HSAGroup\AskHRPro
$env:PYTHONIOENCODING="utf-8"; $env:PYTHONUTF8="1"
python -m uvicorn services.orchestrator_service.main:app --host 127.0.0.1 --port 8081 --reload
```

```powershell
# ── إيقاف ──
netstat -ano | findstr :8081
taskkill /PID <رقم_العملية> /F
```
